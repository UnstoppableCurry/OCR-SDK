Android OCR SDK 封装

基于 PaddleLite v2.10 的中文 OCR 推理封装，提供检测（det）、方向分类（cls）、识别（rec）三阶段流水线。 本页面为静态文档与 API 展示，无法在浏览器中运行推理；请在 Android 设备或模拟器上使用 Demo 应用调用。

minSdk 23 PP-OCRv2 / v3 CPU / OpenCL 可选 Native (.so)

概述

本仓库为 Android 应用内 OCR 推理封装，核心 Java 类位于 com.jwkj.ocr 包。 推理由 Native 库 libNative.so 执行，模型文件位于 assets/models/。

文档来源说明：本页内容均摘自仓库 README、Java/C++ 源码与资源配置，未包含未经代码或 README 证实的性能、准确率或设备兼容性声明。

构建与依赖下载

首次构建时，Gradle 任务 downloadAndExtractArchives（在 preBuild 阶段触发）会自动下载并解压：

  • PaddleLite 库 → app/PaddleLite
  • OpenCV Android SDK → app/OpenCV
  • PP-OCRv2 模型 → app/src/main/assets/models
  • 字典文件 → app/src/main/assets/labels

仓库中已包含 models/ch_PP-OCRv3 模型文件（det_db.nb、rec_crnn.nb、cls.nb）。

模型选择（README）

  • models/ch_PP-OCRv3 — README 注明「性能更好」
  • models/ch_PP-OCRv2 — README 注明「性能略差」；亦为 strings.xml 默认模型路径

API 参考

Predictor.init（完整参数）

boolean init(Context, String modelPath, String labelPath, int useOpencl, int cpuThreadNum, String cpuPowerMode, int detLongSize, float scoreThreshold)

加载模型与字典，并设置检测长边与置信度阈值。模型从 Assets 复制到缓存目录后加载 det_db.nb、rec_crnn.nb、cls.nb。

Predictor.setInputImage

void setInputImage(Bitmap image)

设置输入图像（内部复制为 ARGB_8888）。

Predictor.runModel_SDK

ArrayList<OcrResultModel> runModel_SDK(int run_det, int run_cls, int run_rec)

执行推理并返回结果列表。Native 层以非零值启用对应阶段（见配置参数）。

Predictor.releaseModel

void releaseModel()

释放 Native 预测器资源。

Predictor.isLoaded

boolean isLoaded()

模型是否已成功加载。

OCRPredictorNative

static void loadLibrary()

加载 libNative.so。失败时抛出 RuntimeException。

配置参数

参数说明默认值 / 示例
modelPath Assets 内模型目录 models/ch_PP-OCRv3（Demo）；strings.xml 默认 models/ch_PP-OCRv2
labelPath 字典路径 labels/ppocr_keys_v1.txt
useOpencl 推理设备：0 CPU，1 GPU（OpenCL） 0
cpuThreadNum 推理线程数 4（可选 1 / 2 / 4 / 8）
cpuPowerMode CPU 调度策略 LITE_POWER_HIGH
detLongSize DB 检测预处理时长边上限；超过则等比缩放，否则不处理 960
scoreThreshold DB 后处理 box 置信度阈值，低于此值的 box 被过滤 0.1f
run_det 非 0 时运行检测（ocr_ppredictor.cpp if(run_det)） Demo 使用 1
run_cls 在识别流程中非 0 时运行方向分类（if(run_cls)） Demo 使用 1
run_rec 非 0 时运行识别（if(run_rec)） Demo 使用 1

CPU 调度模式（README）

  • LITE_POWER_HIGH — 高电平运行
  • LITE_POWER_LOW — 低电平运行
  • LITE_POWER_FULL — 全速运行（默认策略）
  • LITE_POWER_NO_BIND — 未绑定状态
  • LITE_POWER_RAND_HIGH — 高随机性模式
  • LITE_POWER_RAND_LOW — 低随机性模式
README 文字将 run_* 的 0/1 含义描述为「0 使用 / 1 不使用」，与 Native 源码中 if(run_det) 等非零即启用的逻辑相反。集成时请以 ocr_ppredictor.cpp 与 MainActivity 示例（均传入 1）为准。

以下示例摘自 README 与 MainActivity.apiSDK()：

public ArrayList<OcrResultModel> apiSDK(Bitmap inputImage) {
    Predictor predictor = new Predictor();

    String sdk_ModelPath = "models/ch_PP-OCRv3";
    String sdk_labelPath = "labels/ppocr_keys_v1.txt";
    int sdk_useOpencl = 0;
    int sdk_cpuThreadNum = 4;
    String sdk_cpuPowerMode = "LITE_POWER_HIGH";
    int sdk_detLongSize = 960;
    float scoreThreshold = 0.1f;
    int sdk_use_run_det = 1;
    int sdk_use_run_cls = 1;
    int sdk_use_run_rec = 1;

    predictor.init(context, sdk_ModelPath, sdk_labelPath, sdk_useOpencl,
            sdk_cpuThreadNum, sdk_cpuPowerMode, sdk_detLongSize, scoreThreshold);

    if (predictor.isLoaded()) {
        predictor.setInputImage(inputImage);
    }

    ArrayList<OcrResultModel> results =
            predictor.runModel_SDK(sdk_use_run_det, sdk_use_run_cls, sdk_use_run_rec);

    predictor.releaseModel();
    return results;
}

结果解析

runModel_SDK() 返回 ArrayList<OcrResultModel>。每个元素字段（README + OcrResultModel.java）：

字段 / 方法类型说明
getLabel()String识别后的文字（由字典索引解码）
getConfidence()float文本序列置信度（README：序列越长通常置信度会变化）
getPoints()List<Point>检测框四个顶点坐标
getClsIdx()float分类下标（README：0→90°，1→180°）
getClsLabel()String方向标签（postprocess 设为 "180" 或 "0"）
getClsConfidence()float分类置信度（README：0–100%）

限制说明

  • 平台：仅 Android 原生应用；本 GitHub Pages 站点为静态文档，不能替代设备端推理。
  • Native 依赖：须打包 libNative.so；加载失败将抛出异常（OCRPredictorNative.loadLibrary()）。
  • NPU：Utils.isSupportedNPU() 当前固定返回 false（Huawei NPU 检测代码已注释）。
  • 网络：首次构建需下载 PaddleLite、OpenCV 与 PP-OCRv2 模型压缩包。
  • 存储权限：Demo 请求相机与外部存储权限以支持选图/拍照。
  • 模型体积：推理模型需随 APK Assets 或自定义路径提供，未包含在线推理服务。
  • Demo 包：README 提供百度网盘 APK 下载链接（提取码：curr），与本页无关的第三方托管。

本页未声明识别准确率、支持设备列表、推理耗时 benchmark 或生产环境 SLA。 如需实测，请在目标 Android 设备上构建 Demo 并自行评估。
